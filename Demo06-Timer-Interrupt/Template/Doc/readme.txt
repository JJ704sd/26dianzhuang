#	systick文件夹中的延时函数，是阻塞延时，在延时过程中不能做其余处理，这里通过使用定时器中断来实现一定时间的延迟
#	只有当计数时间到了之后进入中断，执行对应的处理，其余时间均可处理外部事件。

#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如key.c/key.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用

#	需要注意中断服务函数不能做复杂逻辑代码/耗费时间长的代码，如果有复杂逻辑代码/耗费时间长的代码，
#	建议放置在中断服务函数外，函数内仅做标志位判断
#	定时器参数的时钟分频系数与周期，需要注意对应的最大值，时钟分频系数是uint16_t类型，最大值为65535，周期是uint32_t，4294967295
