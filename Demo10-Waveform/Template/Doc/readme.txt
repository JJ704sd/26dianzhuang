#	波形显示实验，首先需要明白如何显示波形，波形的来源是ADC采集到的数据，每一个数据是一个点，以时间为横坐标，
#	电压值为纵坐标建立平面直角坐标系，依次将相邻的点连接成线，就变成波形图了
#	设计一个画折线函数，在指定区域进行显示，并且需要考虑刷新问题，当数据量大于显示区域，就需要清楚原因的显示进行更新
#	这里我们并没有使用DMA，如果循环刷屏，会发现频闪非常严重，这里使用一种取巧的办法，每当绘制一个点，就清除后一个点的数据
#	这样虽然速度会比整屏刷新慢，但是频闪不严重，方便查看
#	读者也可自行优化显示算法，本设计仅供参考

#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
