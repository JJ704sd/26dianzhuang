# GD32E230 简易示波器（优化版）

本工程对应嘉立创 EDA 教程中的 GD32 简易数字示波器综合案例，保留原有硬件接口：

- PA3：ADC 波形输入，DMA 每帧采集 300 点。
- PA6：TIMER2 输入捕获，用于频率测量。
- PA2：TIMER14 PWM 输出，支持 1 kHz、2 kHz、4 kHz。
- 1.8 英寸 TFT：显示 100 点触发对齐后的波形、Vpp、输入/输出频率和占空比。

## 本版优化

- 使用每帧动态中点的上升沿触发，未找到触发时从第 0 点显示，尾部触发自动限界。
- Vpp 按 `最大值 - 最小值` 计算，平直波形居中显示，绘图坐标严格限制在 0～49。
- DMA 使用单帧模式，主循环处理期间不会覆盖正在显示的采样缓冲区。
- PWM 周期统一按“计数 tick 数”处理，硬件 ARR 写入 `period - 1`，切换频率时保持占空比。
- TIMER2 频率测量支持计数器回绕；断线或只有单个边沿时约 262 ms 后清零。
- KEYD 改为暂停/继续切换，暂停时冻结当前帧，不再进入无限等待循环。
- 中文 UI 使用显式 GBK 字节，源码统一为 UTF-8 后仍可正确索引原字库。

## 验证

在 PowerShell 中执行：

```powershell
& .\Tests\run_tests.ps1
```

主机测试覆盖触发窗口、Vpp、坐标限界和定时器回绕；源码契约检查 DMA、PWM、超时清零、GBK 文本及 Keil 工程引用。最终仍需在真实硬件上检查 PA2/PA3/PA6 接线、按键极性、TFT 显示方向和模拟前端标定。
