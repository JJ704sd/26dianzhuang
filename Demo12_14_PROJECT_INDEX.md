# GD32E230 Standalone Firmware Projects

The three deliverables continue the repository sequence after Demo11:

12. `Demo12-Oscilloscope` - adaptive-trigger oscilloscope firmware.
13. `Demo13-ECG-Monitor` - ECG monitoring and alarm firmware.
14. `Demo14-HESS-ECG-Analyzer` - advanced ECG acquisition, signal-quality and HRV analysis firmware with a HESS startup animation.

Each directory contains an independent specification, `User/main.c`, application
module, Keil project, tests, build log, and numbered HEX file. Only one HEX is
flashed at a time. The original combined `Oscilloscope-ECG` project remains as
the integration baseline.
