#	绘制平面直角坐标系，将其波形还原。

#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如adc.c/adc.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用

#	由于串口发送需要消耗大部分时间，但是波形的变化是非常迅速的，所以这里采用读取一段时间的数据后再一起发送，并在读取过程中进行适当延时
#	因为读取速度很快的话，一个小的接收数组可能不能完整体现出波形的变化
#	这样至少保证这一段时间的波形数据是完整的
