#	LED控制，其实就是控制IO口的高低电平，请自行看板子原理图，观察LED灯的电路结构。配置对应的IO引脚输出为高电平（3.3V）还是低电平（0V）
#	作为第一节课，需要了解整个项目的文件结构
#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如led.c/led.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用
