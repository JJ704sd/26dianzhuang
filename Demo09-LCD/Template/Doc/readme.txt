#	屏幕显示实验，本次项目所使用的是1.8寸TFT屏幕，SPI引脚驱动
#	屏幕厂家一般会将对应的驱动库写好，我们仅需要移植即可，注意删除掉没有用到的字库与函数，这样可以节省内存
#	TFT屏幕清屏函数其实就是将其颜色填充为底色，这样就可将内容进行覆盖填充
#	字库文件在font.h,如果想自己增加显示字库，需要使用取字模软件进行生成

#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如tft.c/tft.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用
