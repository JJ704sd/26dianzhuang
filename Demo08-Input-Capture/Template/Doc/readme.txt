#	定时器除了作为延时计数，还可以输出PWM信号以及进行输入信号捕获，本节课来配置定时器输入捕获
#	输入捕获是通过捕获一个信号的起始上升沿或下降沿，开始计数，然后到第2个对应的上升沿或下降沿结束计数
#	将定时器频率/计数值即可完成对应频率的测量

#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如timer.c/timer.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用

#	配置输入捕获时也需要注意对应周期、比较值等参数的最大值是多少，不可盲目设置
#	输入捕获实验需要连接前面输入端口到输入源（如波形发生器），本实验将对应测量到的频率发送到串口上
