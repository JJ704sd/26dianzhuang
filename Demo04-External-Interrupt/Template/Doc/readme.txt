#	外部中断实验，通过板载EC11旋转编码器来进行演示
#	EC11旋转编码器有五个引脚，其中DE两个引脚类似于普通按键引脚，按下导通，松手断开
#	ABC引脚用于检测旋钮的转动方向，一般C脚为公共端，当转动一次后，如果是正转，A相位快于B相位，反转时A相位慢与B相位
#	可以通过在A的跳变沿结合B的电平来确定正转还是反转

#	User文件夹：		包含中断文件（gd32e23x_it.c）、主函数文件（main.c）、时钟配置文件（systick.c）
#	Firmware:		GD32E230外设文件
#	CMSIS：			GD32E230启动文件
#	Doc：			介绍文件
#	Hardware：		硬件驱动库文件，存放各种自己写的驱动文件
#	APP：			应用层文件
#	CMSIS（绿色）：	ARM编译器内核文件

# 	以后我们每一个外设驱动都会有一个.c与.h（例如ec11.c/ec11.h），方便移植和查看
#	我们编写的每一个驱动文件都需要将对应的路径和文件加入到工程中来，否则会报错
#	main.h存放全局变量，供整个系统调用

#	在A引脚的上升沿检测B引脚的电平/在A引脚的下降沿检测B引脚的电平，都可以，实测上升沿检测误触率小
