# DG1032Z Simulated SpO2/PPG Mode Specification

## Purpose

The third Demo15 mode is a laboratory signal monitor for an analog PPG-like
waveform generated by a RIGOL DG1032Z. It is not an optical pulse-oximeter and
does not calculate a clinical oxygen-saturation percentage.

The supplied instrument photograph is evidence of the generator model only;
it does not contain firmware instructions.

## Equipment contract

- Generator: RIGOL DG1032Z, CH1 output.
- Board input: BNC analog front end routed to PA3 / ADC channel 3.
- Generator load setting: `High Z`.
- Generator and board must share signal ground.
- Keep the external BNC signal between 0 V and 2 V for the initial acceptance
  profile below. Never apply a negative input.
- CH2 is not used because the current PCB exposes only one analog acquisition
  channel to Demo15.

The DG1032Z supports two channels, basic sine/square/pulse waveforms and built-in
arbitrary waveforms including HaverSine and ECG. Demo15 uses only the low-
frequency portion of those capabilities.

## Initial generator profiles

### Profile A: deterministic bring-up

- Waveform: Sine
- Frequency: 1.2 Hz (72 cycles/min)
- Amplitude: 1.0 Vpp
- Offset: +1.0 V
- Phase: 0 degrees
- Output: CH1 on

Expected Demo15 behavior:

- Third mode title reads `SpO2`.
- The bottom-right fields read `SIM` and `PPG`.
- A stable pulsatile waveform is visible at the 2-5 s timebases.
- The pulse field approaches 72 BPM after the detector has seen enough cycles.
- Vpp is nonzero and signal state changes from `WAIT` to `OK` only after a
  qualified pulse has been detected.

### Profile B: pulse-like morphology

- Waveform: built-in HaverSine, or a unipolar arbitrary PPG waveform.
- Frequency: 1.0 Hz (60 cycles/min).
- Amplitude: 1.0 Vpp.
- Offset: +1.0 V.
- Output: CH1 on.

Expected Demo15 behavior:

- The trace shape changes from the sine profile and remains stable.
- Pulse indication is close to 60 BPM after settling.
- Run/hold and 1/2/4/5 s timebases continue to work.

## Display contract

The simulated SpO2 mode displays:

- acquired PA3 waveform;
- run/hold state;
- 1, 2, 4 or 5 s timebase;
- pulse rate in BPM;
- waveform peak-to-peak amplitude;
- `OK` or `WAIT` signal state;
- permanent `SIM` and `PPG` labels.

It must not display a fixed or inferred value such as `98%`. A real SpO2
percentage requires red/infrared optical information or a separately approved
generator encoding protocol.

## Reused implementation

- The 20 kSa/s PA3 DMA remains the only ADC acquisition path.
- The shared stream is decimated to 250 Hz for ECG and simulated PPG display.
- The ECG and PPG pages share the same five-second history to preserve the 8 KB
  SRAM budget.
- The existing qualified-peak detector is reused internally for the displayed
  pulse rate. Its HESS name is an implementation detail, not a third user mode.
- The existing startup animation is retained unchanged at the user's request.

## Acceptance boundary

Host tests and the Keil build only verify code structure. Pulse-rate accuracy,
front-end polarity, amplitude and display stability must be checked on the
physical board with the DG1032Z profiles above. This feature is for electrical
training demonstration and is not a medical device.
